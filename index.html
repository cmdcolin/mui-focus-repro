MUI Menu in an iframe scrolls the page around it

  • Bug: @mui/material 9.5.0 focuses a Menu's first row before Popover positions the menu, while the row still sits at the iframe's top-left.
  • Effect: Firefox scrolls every enclosing page to show a focused element, so this page jumps up to the iframe's top whenever that top is scrolled out of view.
  • Chrome does not scroll for an element inside a position: fixed container, so it never jumps. The panel's focus log still shows the row focused before the menu has a position.

Mode: MUI default · With the workaround (JBrowse's version) · Source

Press Run test in the panel, or scroll down until the dashed top edge of the iframe is above the window and click Open menu yourself.
